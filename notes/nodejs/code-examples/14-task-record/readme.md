# Task: Greet and Record
### Create a Node.js application that:
- Displays a form at the root URL (/) where the user can enter their name
- Accepts the name via a GET request to /process.
- Responds with Hello #name on the browser. (example: Raja => Hello Raja)
- Records each submitted name into a file called names.txt.
    - After first requst names.txt will contain (Raja)
